# موسوعة الإمام المهدي (عج)

موقع عربي تفاعلي ثابت (HTML / CSS / JavaScript) عن الإمام الحجة بن الحسن المهدي (عجّل الله فرجه) من منظور مدرسة أهل البيت (ع).
لا يحتاج إلى خادم ولا قاعدة بيانات ولا خطوة بناء: ارفع المجلد كما هو.

## النشر

**Netlify:** ادخل إلى `app.netlify.com/drop` واسحب مجلد الموقع كاملاً (أو الملف المضغوط بعد فكّه). يعمل فوراً.

**GitHub Pages:** أنشئ مستودعاً، وارفع كل الملفات إلى جذره، ثم من `Settings ← Pages` اختر الفرع الرئيسي والمجلد `/ (root)`. ملف `.nojekyll` موجود.

> تُحمَّل مكتبة Three.js (للمجسمات ثلاثية الأبعاد) من cdnjs، وخطوط Google من الشبكة؛ فيلزم اتصال بالإنترنت أول مرة. وإن لم تُحمَّل المكتبة فالموقع يعمل بكل أقسامه ما عدا المجسمات.

## الأقسام

| الصفحة | محتواها |
|---|---|
| `index.html` | الرئيسية: لوحة حيّة (تاريخ هجري، مناسبة قادمة، يوم الجمعة)، حديث اليوم، بوابات، مجسمات |
| `imam.html` | بطاقة الإمام، النسب، نجمة الأئمة الاثني عشر، الأسماء والألقاب، السيرة |
| `ghayba.html` | الخط الزمني، السفراء الأربعة، التوقيعات الشريفة، الأنصار الـ313، علامات الظهور، وظائف المنتظرين |
| `library.html` | 2057 حديثاً من كمال الدين وغيبة النعماني وغيبة الطوسي والكافي مع روابط أصولها، وأحاديث أهل السنة، وآيات القرآن |
| `duas.html` | 6 أدعية وزيارات بقارئ سينمائي (تمرير تلقائي، حجم الخط، وضع الرقّ) |
| `events.html` | تقويم هجري بـ 52 مناسبة، شموع، عهد الأربعين، عدّاد الفرج، مسابقة، ذاكرة، مصمّم بطاقات |
| `encyclopedia.html` | 19 مقالة، أسئلة شائعة، مصطلحات، كرة أرضية للأماكن |
| `about.html` | منهج التوثيق، المراجع، حدود الدقة |

## بنية الملفات

```
index.html … about.html   الصفحات
404.html                  صفحة الخطأ
css/site.css              نظام التصميم الزجاجي
js/core.js                النواة: التقويم الهجري، البحث (Ctrl+K)، النوافذ
js/fx.js                  المؤثرات: المؤشر، الجسيمات، الإمالة، التمرير
js/mx.js                  المجسمات ثلاثية الأبعاد (Three.js)
js/<page>.js              منطق كل صفحة
js/star.js                النجمة الاثنا عشرية (الشعار والرموز)
data/site.js              كل محتوى الموسوعة (مقالات، أدعية، مناسبات…)
data/lib-*.js             مكتبة الأحاديث (تُحمَّل عند الطلب)
data/land.js              خريطة اليابسة للكرة الأرضية
sw.js, manifest.webmanifest   تطبيق ويب تقدمي (PWA)
```

## كيف وُثّق المحتوى

- **الأحاديث** منقولة حرفياً من قاعدة بيانات thaqalayn.net، ولكل نص رابط إلى أصله. إدراج الحديث لا يعني تصحيحه؛ فالحكم على السند والدلالة للعلماء.
- **آيات القرآن** من مصحف تنزيل بعد مطابقة الترقيم.
- **كتب أهل السنة** مطابقة الأرقام على sunnah.com.
- **الأدعية**: ما عُلِّم «مطابقاً للمصدر» نُقل من كتب الحديث في المكتبة، وما سواه علّمناه صراحةً بأنه نص متداول يحتاج إلى مقابلة بمفاتيح الجنان أو المصدر المطبوع.
- لا يتضمن الموقع تحديداً لموعد الظهور، تأسّياً بالنهي الوارد: «كذب الوقّاتون».
- قد يختلف التاريخ الهجري يوماً بحسب رؤية الهلال؛ وفي صفحة الفعاليات خيار لضبطه.

## تعديل المحتوى

كل نصوص الموسوعة في `data/site.js` (كائن `window.D`). عدّل القيم أو أضف عناصر بالبنية نفسها، ولا حاجة إلى أي أداة بناء.

اللهم عجّل لوليك الفرج.
